# Customized Skills Overlay

This folder is a product-owned placeholder for custom commands and workflows.

## Purpose

Use this namespace for product-specific command documentation that supplements the registered skills catalog.

## Constraints

- Do not duplicate a registered skill body here.
- If a custom command becomes reusable across the repository, promote it to a registered `skills/<name>.md` skill through the standard skill contract.
- Keep product-specific skill documentation compatible with [AGENTS.custom.md](../../AGENTS.custom.md) and the repository COD.

## Ownership

The product team maintains this overlay.
